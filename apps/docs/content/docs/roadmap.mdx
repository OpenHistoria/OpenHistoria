description: Product and documentation areas that should keep improving.
---

## Product Areas

- Richer country setup with clearer initial constraints.
- Better scheduled-event visibility before major jumps.
- More map-backed directive workflows.
- Stronger persistence and restore flows.
- Sharper feedback when a directive is too vague.

## Documentation Areas

- Scenario authoring guide.
- Prompt contract reference.
- Persistence schema reference.
- Deployment guide for production hosting.
- Troubleshooting guide for OpenRouter and Supabase setup.

## Quality Bar

Roadmap work should improve the game loop, reduce ambiguity, or make contribution safer. Avoid adding features that only expand surface area without making the simulation more understandable or more playable.
