OpenHistoria is a grand strategy sandbox where the player leads a country through divergent history. The application combines an interactive world map, event-driven simulation, directives, scheduled developments, and AI-authored briefings into a compact strategy loop.

## What This Documentation Covers

This site is the working manual for the project:

- **Players** get a fast path into starting a scenario, issuing directives, reading briefings, and understanding time jumps.
- **Designers** get a shared vocabulary for countries, events, directives, decisions, and simulation pacing.
- **Developers** get the architecture, workspace layout, local setup, and contribution rules needed to change the product safely.
- **Operators** get the deployment and environment expectations that keep the app predictable.

## Product Shape

OpenHistoria is built around a clear loop:

1. Choose a country and starting context.
2. Read the current state of the world and the next scheduled pressures.
3. Queue directives that express political, military, economic, or diplomatic intent.
4. Advance time by a fixed period or to the next major event.
5. Review the simulated consequences, decide on urgent choices, and keep steering.

The map is not decoration. It anchors the state of the world, makes geography visible, and gives directives a concrete place when location matters.

## Documentation Principles

Docs should stay close to how the product actually works. Prefer specific examples over broad claims, name the code paths that own behavior, and update the relevant page whenever a workflow changes.
