## Runtime

The app targets Node.js 20 or newer and uses Bun as the package manager. Keep lockfile changes generated by Bun.

## Environment Variables

The root Turbo configuration forwards these public variables:

- `NEXT_PUBLIC_SUPABASE_URL`
- `NEXT_PUBLIC_SUPABASE_ANON_KEY`
- `NEXT_PUBLIC_MAP_REGIONS_URL`

Server-only secrets should not use the `NEXT_PUBLIC_` prefix.

## Supabase

Local Supabase commands are available from the root package:

```bash
bun supabase:start
bun supabase:stop
bun supabase:reset
```

Use reset carefully because it rebuilds local database state.

## Docs Deployment

The docs app is a normal Next.js app. Build it independently with:

```bash
bun --filter docs build
```

If the docs are deployed beside the game app, keep their environment and routing separate. The docs app is intentionally standalone so it can be hosted independently or wired into a multi-zone setup later.
